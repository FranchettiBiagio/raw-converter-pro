## 1. Premessa

Franchetti Raw Converter Pro ("l'Applicazione") è un software desktop per Windows progettato per convertire file RAW in JPEG con watermark copyright. La presente informativa descrive come l'Applicazione gestisce i dati degli utenti in conformità al Regolamento UE 2016/679 (GDPR) e alla normativa italiana applicabile.

---

## 2. Dati Raccolti

**L'Applicazione NON raccoglie, memorizza, trasmette o elabora alcun dato personale.**

| Categoria di dati | Raccolti? | Dettagli |
|-------------------|-----------|----------|
| Dati anagrafici (nome, email) | ❌ No | Nessuna registrazione richiesta |
| Dati di utilizzo / telemetria | ❌ No | Nessun analytics, crash reporting, tracking |
| Indirizzo IP / identificatori dispositivo | ❌ No | Zero connessioni di rete |
| File elaborati (RAW, JPEG) | ❌ No | Elaborazione 100% locale |
| Metadati file (EXIF, GPS, timestamp) | ❌ No | Non estratti, non salvati, non trasmessi |
| Preferenze utente | ❌ No | Non persistite su disco |
| Log applicazione | ❌ No | Solo in memoria, sessione corrente |

---

## 3. Modalità di Elaborazione

### 3.1 Elaborazione Locale Esclusiva
Tutte le operazioni avvengono **esclusivamente sul dispositivo dell'utente**:
- Lettura file RAW selezionati dall'utente
- Decodifica RAW → RGB (libreria LibRaw)
- Ridimensionamento, watermark, encoding JPEG (libreria Pillow)
- Scrittura file JPEG nella cartella di destinazione scelta dall'utente

### 3.2 Nessuna Comunicazione di Rete
L'Applicazione:
- Non apre socket di rete
- Non effettua richieste HTTP/HTTPS
- Non include librerie di rete (curl, OpenSSL, WinHTTP, WinINet)
- Non verifica aggiornamenti automaticamente
- Non invia report di errore

### 3.3 Nessuna Persistenza
- Nessun file scritto in `%APPDATA%`, `%LOCALAPPDATA%`, `Registry`
- Nessun file temporaneo creato fuori dalla cartella di output utente
- Impostazioni UI mantenute solo in memoria per la durata della sessione
- Chiusura applicazione = cancellazione completa stato memoria

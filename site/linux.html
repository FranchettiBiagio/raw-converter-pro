02Prima di iniziare

Non serve essere programmatori. Su Linux sono cinque comandi da incollare nel terminale; su macOS c'è un file di avvio automatico. In entrambi i casi serve Python con la sua libreria grafica, Tk.

VoceRichiesta
Python3.11 o 3.12. Con 3.14 o superiore il batch può comportarsi male: la build avvisa.
TkLa libreria grafica di Python. Su molte distribuzioni non è installata di serie.
Spazio su discoCirca 1 GB tra dipendenze e build.
RAM2 GB minimo, 8 GB consigliati con RAW da 40-60 MP.
SistemaLinux x86_64; macOS Intel o Apple Silicon.

Tk, comando per distribuzione

DistribuzioneComando
Debian, Ubuntu, Mintsudo apt install python3-tk
Fedorasudo dnf install python3-tkinter
Arch, Manjarosudo pacman -S tk
openSUSEsudo zypper install python3-tk
macOS con Homebrewbrew install python-tk@3.12

Su macOS va benissimo anche la Python di python.org, che include Tk: in quel caso non serve installare altro.

03Linux, passo per passo

Questa è la procedura provata su Linux Mint 22.3 in macchina virtuale, con Python 3.12.0 e PyInstaller 6.22.3. Vale allo stesso modo su Ubuntu e Debian.

1

Scompatta l'archivio

Apri il terminale nella cartella dove hai scaricato lo ZIP, di solito Scaricati.

Terminale
cd ~/Scaricati
unzip Franchetti_Raw_Converter_Sorgente_2.58.2.zip
cd FranchettiRawConverterPro-2.58.2
2

Installa Tk, se manca

Se al primo avvio compare No module named tkinter, manca Tk. Su Debian, Ubuntu e Mint:

Terminale
sudo apt update
sudo apt install python3-tk
3

Crea l'ambiente Python

Un ambiente separato tiene le dipendenze del programma lontane dal resto del sistema. Si crea una volta sola.

Terminale
python3 -m venv .venv
source .venv/bin/activate

Il prompt cambia e mostra (.venv) all'inizio della riga. Per uscire: deactivate.

4

Installa le dipendenze

Il primo download è di circa 250 MB: comprende LibRaw, Pillow, NumPy, OpenCV e le altre librerie.

Terminale
python3 -m pip install --upgrade pip
pip install -r requirements.txt
5

Avvia il programma

Si apre la finestra normale: seleziona la cartella dei RAW, la destinazione e premi «Avvia conversione batch».

Terminale
python3 main.py

Alla prima esecuzione compare nel log la riga di avvio, con versione di Python, PID e metodo dei processi: serve a capire subito come sta girando il programma.

6

Facoltativo: compila l'eseguibile

Se preferisci non dipendere dal terminale, costruisci la cartella eseguibile. Su Linux il risultato è dist/FranchettiRawConverterPro/ e va tenuto intero.

Terminale
python3 build_exe.py
./dist/FranchettiRawConverterPro/FranchettiRawConverterPro

La build usa --onedir: i file restano accanto all'eseguibile e non vengono più estratti in /tmp a ogni avvio. È la combinazione che ha chiuso il consumo anomalo di memoria.

Risultato atteso: build da 14,9 MB, batch di un RAF X-Trans da 26 MP a 3000 px in circa 16 secondi su 2 vCPU, memoria stabile durante tutta la sessione.

04macOS, passo per passo

Il pacchetto per macOS contiene un avvio automatico: non devi digitare comandi. Questa parte non è mai stata provata su una macchina Apple reale: considerala sperimentale e, se qualcosa non torna, scrivi all'autore.

1

Scompatta e fai doppio clic

Scompatta lo ZIP, tieni la cartella dove vuoi e apri Avvia Franchetti Raw Converter.command. La prima volta macOS può chiedere conferma: clic destro sul file, poi Apri, poi Apri. Se il doppio clic non fa nulla, scegli Apri con → Terminale.

Al primo avvio il file prepara l'ambiente dentro la cartella e scarica le dipendenze (circa 250 MB, serve internet solo quella volta). Le volte successive il programma si apre in pochi secondi.

Se preferisci non usare il file di avvio, i comandi manuali sono al passo 4.

2

Se macOS blocca il file scaricato

Il file arriva dal browser e porta il segno di quarantena. Tre modi, dal più semplice:

  1. clic destro sul file → Apri → Apri;
  2. Impostazioni di Sistema → Privacy e Sicurezza → in fondo, Apri comunque;
  3. da Terminale, nella cartella del programma:
Terminale
xattr -dr com.apple.quarantine .

La quarantena riguarda il file scaricato, non il programma in sé: una volta aperto, non viene più chiesta.

3

Serve Python con Tk

Il pacchetto non include Python: usa quello del sistema. Va bene la versione di python.org, che include Tk. Se usi Homebrew, aggiungi il pacchetto grafico della stessa versione:

Terminale
brew install python-tk@3.12
python3 --version

Se manca Python, l'avvio automatico lo dice e si ferma: non installa nulla al posto tuo.

4

In alternativa: da terminale

Gli stessi passaggi a mano, se preferisci vedere cosa succede. Il terminale si apre da Applicazioni → Utility → Terminale.

Terminale
cd ~/Downloads
unzip Franchetti_Raw_Converter_macOS_2.58.2.zip
cd FranchettiRawConverterPro-macOS-2.58.2
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
Nessuna firma, nessuna notarizzazione. La build macOS produce un singolo eseguibile, non un bundle .app con icona. Per distribuire un .dmg che si apre con un doppio clic servirebbe l'Apple Developer Program (99 $ l'anno): non è previsto.

Se compili su un Mac Apple Silicon, l'eseguibile funziona su Apple Silicon. Per Intel serve compilare su Intel, oppure una build universale, più delicata da preparare.

05Compilare l'eseguibile

La build serve solo se vuoi un programma da avviare senza terminale. Richiede le dipendenze già installate nell'ambiente virtuale.

Terminale
source .venv/bin/activate
python3 build_exe.py
RisultatoDove
Linuxdist/FranchettiRawConverterPro/ — cartella intera, con l'eseguibile dentro
macOSdist/FranchettiRawConverterPro — singolo eseguibile, senza bundle .app

Icona, proprietà del file e manifest sono opzioni Windows: su Linux e macOS la build le salta e lo scrive nell'output. Non è un errore.

Due variabili, quando servono

VariabileEffetto
FRC_ONEFILE=1Torna al pacchetto singolo. Sconsigliato: si ri-estrae in /tmp a ogni avvio.
FRC_THREADS=1Forza il batch con i thread invece dei processi.
Python 3.14 o superiore? Su Linux il metodo predefinito per i processi diventa forkserver. Con un programma impacchettato è la combinazione che manda in crash l'applicazione a catena. Per la build usa Python 3.11 o 3.12.

06Log e diagnosi

Il log non è sul Desktop: sta nella cartella dati dell'utente, dove il programma ha sempre il permesso di scrivere.

SistemaPercorso
Linux~/.local/share/FranchettiRawConverterPro/franchetti_log.txt
macOS~/Library/Application Support/FranchettiRawConverterPro/franchetti_log.txt

Per le ultime righe, senza aprire editor:

Terminale · Linux
tail -n 40 ~/.local/share/FranchettiRawConverterPro/franchetti_log.txt

Su Linux c'è anche uno script che avvia il programma, campiona ogni tre secondi memoria libera e numero di copie del processo, e scrive un report:

Terminale · Linux
bash tools/diagnosi_linux.sh
# report: ~/diagnosi-frc.txt

Nel log trovi anche le righe che iniziano con Anteprima: dicono se il problema è la decodifica del RAW o il disegno dell'immagine.

07Cosa è dichiarato sperimentale

Nessuna promessa oltre ciò che è stato provato. Questi sono i limiti reali, al momento.

Linux è stata provata su una sola distribuzione, in macchina virtuale: Linux Mint 22.3, 2 vCPU, 8 GB. macOS non è mai stata provata su una macchina reale.

Pacchetti prontiNessun .deb, .rpm, .AppImage, .dmg o .app
Firma AppleAssente: il file scaricato va aperto con «Apri comunque»
Icona e proprietàNon impostate su Linux e macOS

08Problemi comuni

I messaggi che capitano più spesso, con la soluzione. Se non trovi il tuo, scrivi all'autore con il log: si parte da lì.

MessaggioCosa fare
No module named tkinterManca Tk: installalo con il comando della tua distribuzione (sezione 02).
ModuleNotFoundError: rawpyL'ambiente virtuale non è attivo: source .venv/bin/activate, poi reinstalla le dipendenze.
Permission deniedSull'eseguibile: chmod +x dist/FranchettiRawConverterPro/FranchettiRawConverterPro. In alternativa avvia python3 main.py.
L'app Mac non si apreClic destro → Apri, oppure xattr -dr com.apple.quarantine sulla cartella.
Memoria che cresce, processo uccisoUsa la build --onedir con Python 3.11/3.12 e non FRC_ONEFILE=1.
Anteprima PRIMA/DOPO vuotaApri il log e cerca le righe «Anteprima»: indicano se fallisce la decodifica o il disegno.
python3: command not foundInstalla Python dal gestore pacchetti o da python.org, poi riapri il terminale.
Batch lentoControlla quanti core usa il programma nelle opzioni: su macchine virtuali i core disponibili sono pochi.

09Segnalare un problema

Una segnalazione con quattro informazioni si risolve quasi sempre al primo scambio. Scrivi a reportage@libero.it indicando:

Sistema

Distribuzione e versione, per esempio «Linux Mint 22.3» oppure «macOS 15.2, M2».

Python

L'output di python3 --version, e se hai usato python.org, Homebrew o conda.

Passi e log

Cosa hai fatto prima dell'errore, il file franchetti_log.txt e, su Linux, ~/diagnosi-frc.txt.

Scrivi all'autore
Nessun account, nessuna piattaforma esterna: la risposta arriva via email.

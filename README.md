Franchetti Raw Converter Pro
    
Professional RAW to JPEG converter with copyright watermarking for photographers.
Franchetti Raw Converter Pro is a lightweight, portable Windows application that converts camera RAW files to optimized JPEG images with customizable copyright watermarks. Designed for professional photographers and enthusiasts who need batch processing with zero configuration overhead.

Powered by LibRaw 0.21+ via rawpy for maximum compatibility and quality.
🔧 Processing Capabilities
Batch conversion — Process entire folders recursively (hundreds of files)
Flexible resizing — Long edge: 640–4000 px presets or original resolution
JPEG quality control — 50–100 scale (default 85: optimal quality/size balance)
Lanczos resampling — High-quality downscaling preserves detail
Multi-threaded — Background processing keeps UI responsive
🏷️ Copyright Watermarking
Custom text — Any Unicode string (e.g., © Franchetti 2024, Photo by John Doe)
Font size — 8–48 pt (default 14 pt: subtle, professional)
Position — Bottom-right with 1% margin
Visibility — White text (80% opacity) + subtle black shadow for readability on any background
Non-destructive — Original RAW files never modified
📁 File Management
Preserve original names or add custom prefixes
Auto-collision handling — Appends _1, _2… to avoid overwrites
Mirror folder structure option (planned v1.1)
Drag & drop folder or file selection
💻 User Experience
Native Windows 10/11 UI — Tkinter with modern styling
Real-time progress — Percentage, file counter, current file preview
Color-coded logs — Green (success), Red (error), Blue (info), Orange (warning)
Cancellable operations — Stop batch processing at any time
Portable — Single 32 MB .exe, no installation, no registry, no telemetry

    📸 Come Aggiungere le Tue Foto/Screenshot

    1. Crea cartella docs/screenshots/ nel repo
    2. Carica i tuoi screenshot (1200×675px, PNG/JPG, <500KB cadauno)
    3. In docs/index.html, sostituisci src="https://via.placeholder.com/..." con src="screenshots/tua-foto.png"
    4. Modifica alt e screenshot-caption con le tue descrizioni
    5. Commit & Push → Il sito si aggiorna automaticamente in 1-2 min

    Formato consigliato: 1200×675px (16:9), PNG per UI, JPG per foto, <500KB per performance.
